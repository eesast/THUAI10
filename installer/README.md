# Installer

## 简介

THUAI10选手包下载器兼启动器

## 目标

### 基本目标

- 为 Windows 编写桌面应用程序，推荐使用Avolonia，目标平台 .NET 10，需要实现以下功能：
  - 选手包下载
  - 检查选手包更新情况
  - 为下载器添加 "暂停与断点续传" 的功能

## 重要目标

- 设计美观的UI，便于选手操作
- 支持Mac平台
- 使用 MVVM 或其他设计模式

## 提高目标

- 与网站组对接，支持账号密码登录
- 拉取天梯队伍信息和数据分析
- 集成 THUAI10 使用文档
- 集成启动器功能

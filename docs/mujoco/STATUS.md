## 参赛、赛制与运行维护 v0.4

已完成：

- 可直接上传的 G1 行走与简单深度避障入门包，随包提供固定 Holosoma ONNX 权重、机器人参数、配置与 Apache-2.0 许可。最小接口模板继续保留。入门包不包含完整城市搜索、瞄准和自主起身算法。
- 多布局循环赛，固定参赛版本；每组对手在相同布局下互换出生位置和私人任务组。胜 3、平 1、负 0，依次比较积分、任务净分和任务总分，仍相同则并列。全部场次完成后统一发布赛事总榜和回放。
- 城市 `mixed-v1` 任务集增加杯子、饮料瓶、包裹盒、球和罐子，使用对应参考图、任务文字及同色异形干扰物。历史任务集保留，传感器接口保持原样。
- 运行诊断提供有效响应次数、平均／95 分位／最大响应耗时、生命与耗时曲线、裁判事件计数；练习支持两次运行对比。
- 运行环境发布支持原 ONNX CPU、PyTorch CPU 和 CUDA 配方。框架实际导入、张量运算与 GPU 检测通过后才发布；已使用的镜像摘要固定，复用现有镜像，不覆盖历史环境。对局双方必须使用相同环境。
- 每日备份数据库和原始提交 ZIP，保留最近七份完整快照；三十天前的终止练习清理文件、保留成绩，正式比赛保留。提供磁盘／维护／场次失败站内告警、立即备份、到期清理、恢复到全新目录的工具。
- 服务重启后使用原提交、种子与出生配置重新排队，最多自动恢复两次；失败场次可按原配置重试。该恢复是重跑，不是从物理中间状态续算。
- 未变化的图像及任务参考图使用传输缓存，在容器内恢复完整、独立的观测。控制仍为 50 Hz，图像仍为 10 Hz。网页评测统一关闭策略摄像头阴影，物理与深度遮挡保留。运行前后校验源代码与配置摘要，变更后要求重启，避免混用平台版本。

## 上传、部署与仿真闭环 v0.3

本轮增加根目录 `一键部署.cmd`，以及管理员“比赛管理 → 运行环境 → 一键部署并自检”。部署自动校验资源、启动已安装的 Docker Desktop、准备固定镜像，再用真实 MuJoCo、双 RGB-D 与两个独立策略容器完成通信自检；检查通过后恢复队列。正在运行的场次会阻止部署，已使用环境的镜像摘要不允许被重新构建覆盖。

选手可勾选“检查通过后自动开始城市练习，并返回成绩与回放”。上传后先安全解压、验证机器人与入口，再在隔离容器内编译全部 Python 文件，之后才导入策略并检查实际动作；未导入的辅助文件存在语法错误也会报告文件名和行号。运行检查失败可重新检查同一版本，重复点击复用未完成任务；静态错误需要修复后上传新版本。

模板新增 `README.md`、`robot.json` 和机器人控制声明，支持按完整关节名称重排模型输出。明确拒绝不兼容本体、单位、控制方式或关节数量。详见 [选手提交指南](SUBMISSION_GUIDE.md)。练习只运行策略评测，不优化参数或保存新权重。

验收记录：全量 61 项自动检查通过；随后新增重检的权限、版本不可变和任务去重检查，并复跑上传工作流 11 项，共 62 项独立自动检查通过。另完成 21 项真实 Docker + MuJoCo 集成验收，涵盖一键部署、全包编译、28 关节输出拒绝、显式关节重排、上传自动进入 2 秒城市练习、1 秒房间正式比赛、成绩发布、真实回放、跨账号权限与隐藏种子保护。

本轮还通过真实浏览器点击完成管理员一键部署、选手上传、自动练习、成绩与回放播放；浏览器练习缩短为 1 仿真秒，仅用于接口闭环验收。生产默认仍为 60 仿真秒。截图保存在 `artifacts/platform_validation/ui-v03/`，真实集成结果保存在 `artifacts/platform_validation/integration.json`。验收使用独立目录和会话 Cookie，未向正式账号库写入测试账号。这些检查证明通信与裁判链路可用，不代表模板策略具备自主行走或搜索能力。

### 规则与接口

初版 22 项自动检查通过；街具与内饰更新后扩展到 33 项，覆盖：

- 公共目标同时命中分摊，以及双方同周期致命射击；
- 打错个人目标、打墙、重复命中、冷却与禁火期间请求；
- 实际射线击中对手身体并造成扣血与禁火；
- 实际目标命中与障碍物优先遮挡；
- 倒地计时、稳定自主起身、保血复位、死亡流程优先级；
- 无效动作、关节接口、RGB-D 格式与图像更新周期；
- 选手异常和超时不阻断另一个选手，过期开火指令被丢弃。
- 新街区入口和藏点连通、实际遮挡可见性、无人机高度层和间距、动态角色轨迹恢复。
- 修复 Windows 短回放结束时窗口线程尚未退出、GLFW 已释放造成的异常退出；增加关闭顺序回归检查，并实际播放验证。

### 开源运控适配

默认采用 Holosoma 29-DoF FastSAC，而不是直接套用宇树 12 关节权重。

- 静止 20 仿真秒：全程站立，最低骨盆高度约 0.739 米。
- 前进测试 20 仿真秒，前 2 秒静止、之后给定 0.25 米/秒指令：前进约 3.36 米，横向漂移约 0.41 米，最低骨盆高度约 0.748 米，全程未摔倒。
- 本轮没有训练新权重，没有吊架或外加支撑力。上述是特定配置下的转移验证，不代表复杂动作或所有指令均已通过。

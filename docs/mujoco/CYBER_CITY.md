# NEON DISTRICT · 赛博街区

本场景用于视觉搜索、狭窄空间通行和动态交通避让。活动范围约 61.2×66 米：保留原主街，向北拓展，垂直于道路的总宽度从 33 米翻倍到 66 米。二十个区域都有真实开放入口、室内或庭院空间、家具遮挡及可搜索藏点。

两条平行道路中心相距 30 米：霓虹大道采用蓝紫色、高楼和科幻设施；烟火生活街采用暖色砖铺地面、黄色道路标线、低层店面、中文招牌、灯笼和酒店楼体。两条连接路、后巷及中央步行通道连通街区。高架空轨和北侧天际线移到扩展后的场地外，避免占据新道路。

视觉以蓝紫色夜景为基础，加入暖金、红色、橙色与绿灯，形成有冷暖变化的商业街。八处店铺上方增加退台高楼；外围分为中景楼群与远景天际线，楼高、宽度、窗格与色彩各有差异，另有高架空轨、列车、远处连桥、星空与带环天体。

八种原创广告画面用于楼体、街边灯箱、菜单与机厅屏幕。日常店铺另有中文店招、品类菜单和电脑桌面画面，均为程序绘制的场景贴图。酒店当前可进入的是地面大堂，上部楼体用于背景。

两条道路两侧各有连续的行道树和错位座椅，共 32 棵行道树，加上公园、广场为 40 棵树，混合绿色和金色树冠。新增或细化 36 张木质长椅、8 块街牌、2 块公共导览牌、8 组垃圾桶及一处棋牌休憩桌。树池包含格栅、土面和树根灯圈；长椅包含木板、靠背、扶手、金属支架和低位灯带。主要家具与树池有碰撞形体，门前保留直接接近的通道。

15 个商业场所采用六类地面：木地板、水磨石、大理石、地毯、水泥及瓷砖。加入护墙和压条、柜体抽屉与拉手、隔挡边框、品牌背景墙、盆栽、吊灯与顶灯；咖啡店有出水口和餐具，餐饮店有蒸笼边圈和排烟管，糖葫芦柜台有支杆和包装，五金店有小零件分格，酒店有前台终端和门卡，网吧有显示器底座、鼠标和机箱风扇，洗衣机有金属门圈、旋钮和叠放毛巾。

公共导览牌展示商家与街道的示意布局，可通过机器人摄像头读取，不包含随机任务藏点。开发者通行地图仍不向选手提供。

## 藏点和通行

- 80 个候选藏点，每区域 4 个。每局从每区域选择 1 个目标，共 20 个。
- 八个公共任务，以及每名选手六个个人任务；扩展后仍保持双方数量相同。
- 挡板主要遮蔽街道方向的视线，选手需要进入区域并改变观察位置。
- 开放入口净宽约 2.8 米，内部设置可绕行的柜台、柱子与绿化；地面保持齐平。
- 开发者使用半径 0.27 米的二维膨胀通行模型，验证两个出生点、两条道路、连接路和二十个入口连通，80 个搜索位置都可达。
- 额外检查出生位置净空、店门前接近通道，以及程序化巡逻角色的完整往返区间，避免家具占用出生点或巡逻路线。
- 从这些搜索位置向对应藏点作射线检查，包含装饰表面，80 个藏点均有可见路径。

通行检查是几何验收，不代表已经训练出能走遍街区的运动策略。实际全身控制、搜索和避障仍由选手策略完成。开发者地图、真实目标位置和验证结果保存在输出文件，不通过参赛观测接口发送。

## 动态角色

两条路各有三辆悬浮车，在地图外约 ±36 米处循环；新街加入黄色出租车灯，车速更慢。同一车道车辆保持相同速度。三个人形巡逻机器人、八只机械狗分布在两街，沿固定区间往返。

七架无人机在约 4.2、8.8、15.5 米三个高度层沿椭圆航线飞行，四架位于原街、三架位于新街；不同速度与相位形成交错效果。另有一列三节空轨列车在北侧外围移动。

这些角色使用 MuJoCo 的 mocap 固定轨迹机制，属于可复现的程序控制，不是强化学习策略。车辆和地面角色提供真实接触表面；无人机和空轨列车为无碰撞背景装饰。固定路线角色不会因选手阻挡而自动停车或改道。

车辆每个物理步更新（500 Hz），其余背景角色按固定 50 Hz 更新。全部 97 个角色及肢体的 mocap 位置、姿态与参赛机器人状态一起记录到轨迹，回放时恢复同一帧状态。

## 交通碰撞惩罚

仅在真实接触且接触力达到阈值后判罚，不按距离接近扣血。

| 参数 | 默认值 |
| --- | --- |
| `traffic_damage` | 每次扣 15 生命 |
| `traffic_contact_cooldown` | 同一辆车对同一选手 2 秒冷却 |
| `traffic_min_force` | 接触力阈值 5 N |
| `traffic_enabled` | true，可用于关闭车辆开展分阶段练习 |

持续受挤压时，在冷却到期后才允许再次判罚，避免一个接触被每个物理步重复扣血。交通致死沿用原来的延迟重生机制，任务状态和得分规则保持一致。充电区当前为场景地标，不增加回血规则。

`dependency/shell/mujoco/check_traffic.py` 将机器人初始位置布置在车道上，执行真实物理接触试验，输出伤害事件、轨迹和动图。该文件是受控验收场景，不是自动避车演示。

## 观看

先完成资源安装，再从仓库根目录执行：

```powershell
.\logic\mujoco\.venv\Scripts\python.exe -m embodied_arena run --scene cyber_city --viewer --realtime --output logic/mujoco/artifacts/city-demo
```
